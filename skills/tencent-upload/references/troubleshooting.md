# 视频号故障排查

## Cookie 无效

先执行 `sau tencent check --account <name>`。无效时执行：

```bash
sau tencent login --account <name> --headed
```

登录二维码应直接展示或发送给用户扫码。

## 封面未设置

确认横封面为四比三、竖封面为三比四，文件可读且是平台支持的图片格式。用 `--headed --debug` 重跑单个测试任务并检查页面和诊断截图。

## 发布后仍返回失败

不要立即重跑。先到视频号内容管理确认作品是否已经出现，防止页面跳转超时导致重复发布。确认没有作品后才能重新入队。

## 自动任务需要扫码或验证码

停止该账号后续任务，向用户发送二维码或明确的验证码请求。其他账号任务可以继续，不能用另一个账号 Cookie 替代。
